# Checklist Feature - Implementation Guide

## What's New

A lightweight, collapsible checklist for tracking tasks during your focus session.

## Features

✅ **Collapsible Section** - Click the caret (▶/▼) to show/hide
✅ **Add Tasks** - Simple "Add task" button when empty
✅ **Nested Steps** - Hover on any task to add sub-steps
✅ **Quick Delete** - Hover to reveal "X" button
✅ **10 Item Limit** - Prevents list from getting overwhelming
✅ **Persistent Storage** - Saved in chrome.storage.local
✅ **Keyboard Support** - Press Enter to add tasks

## User Flow

### Initial State

- Section collapsed by default (▶)
- Click header to expand (▼)
- Shows single "Add task" button

### Adding a Task

1. Click "Add task" button
2. Text input appears with "Add" and "Cancel" buttons
3. Type your task and press Enter or click "Add"
4. Task appears as a list item

### Adding Nested Steps

1. Hover over any task
2. "add steps" button appears
3. Click it to add sub-tasks
4. Sub-tasks are indented with a left border

### Deleting Items

1. Hover over any task
2. "X" button appears on the right
3. Click to delete (removes nested items too)

### Item Limit

- Max 10 items total (including nested)
- Add buttons disappear when limit reached
- Keeps the list focused and manageable

## Storage

Data is stored in:

```javascript
chrome.storage.local.get('checklist');
```

Structure:

```javascript
[
  {
    text: 'Research React frameworks',
    steps: [
      { text: 'Check Next.js docs', steps: [] },
      { text: 'Compare with Remix', steps: [] },
    ],
  },
  {
    text: 'Write client proposal',
    steps: [],
  },
];
```

1. Replace popup.html with updated version
2. Replace popup.js with updated version
3. Add checklist-styles.css content to your popup.css
4. Reload extension
