# Testing AI Relevance Checks

## Method 1: Dev Trigger Button (Added!)

I've added a 💬 button next to the reset button that appears only during active sessions.

**Usage:**

1. Start a focus session
2. Look for the 💬 button in the top-right (next to 🔄)
3. Click it to immediately trigger an AI relevance check
4. Check should appear as a notification and/or in the popup

## What to Expect

When triggered, the AI check will:

1. Look at your recently visited URLs
2. Generate a contextual question using Claude API
3. Show a Chrome notification
4. Log to console: "Checking for summary (attempt X/15)..."

## Troubleshooting

**Button doesn't appear?**

- Make sure you have an active session
- Check that trigger button is in HTML
- Verify JavaScript didn't error (check popup console)

**No notification appears?**

- Check browser notification permissions
- Look in Chrome notifications (system tray)
- Check background service worker console for errors

**API errors?**

- Verify API key is valid
- Check that CORS header is included
- Look for error logs in service worker console
